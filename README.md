# tvjoe

Streaming-Client für Live-TV (Rust, GTK4/libadwaita, libmpv). Ziel: öffentlich-rechtliche Sender aus eigenen M3U-Listen, schneller Start, geringe CPU-Last.

Status: Projektgerüst (Meilenstein M0), noch keine Funktion.

## Bauen

```bash
cargo build
cargo test
```
